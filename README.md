# PsychicHeroes Mobile Application

Cross-platform mobile application for **PsychicHeroes** built using Flutter, targeting iOS and Android.

## Features & Modules

- **Core Framework**: Clean modular architecture using Provider state management.
- **Authentication**: Email/Password and Phone OTP Sign In / Sign Up, password reset.
- **User Module**: User profile view, edit profile, billing address management, notification history.
- **Main Shell**: Responsive bottom navigation and side drawer menu.
- **Home Module**: Hero promotional sliders, psychic category horizontal filters, live advisor list with online/busy status.

## Getting Started

1. Ensure Flutter SDK (>=3.0.0) is installed.
2. Run `flutter pub get` inside this directory.
3. Launch with `flutter run` for iOS simulator or Android emulator/device.
